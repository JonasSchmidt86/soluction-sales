# Documentação do projeto

Esta pasta centraliza toda a documentação de features e regras de negócio do
sistema. **Novos documentos de funcionalidade devem ser criados aqui**, para
manter tudo num só lugar.

> O `README.md` da raiz do projeto continua sendo o ponto de entrada geral
> (setup, como rodar). Aqui ficam os documentos por assunto/feature.

## Índice

| Documento | Assunto |
|---|---|
| [COMISSOES.md](COMISSOES.md) | Como o módulo de comissões funciona (regras, apuração, ajustes, telas). |
| [ORCAMENTOS_README.md](ORCAMENTOS_README.md) | Módulo de orçamentos. |
| [ORCAMENTOS_EDITOR_VISUAL.md](ORCAMENTOS_EDITOR_VISUAL.md) | Editor visual de orçamentos. |
| [EDITAR_ITENS_VENDA.md](EDITAR_ITENS_VENDA.md) | Edição de itens de venda. |

## Convenção

- Um arquivo `.md` por feature/assunto, nomeado em MAIÚSCULAS com `_` (ex.: `COMISSOES.md`).
- Ao criar um documento novo, adicione-o ao índice acima.
